# Biomimicry: Nature's Master Blueprints 🌿🚄

An interactive, editorial-grade web presentation built with clean frosted glassmorphism, dynamic ambient illumination, and built-in rehearsal notes. Designed for a 5-minute academic keynote at the Department of English, Central University of South Bihar (CUSB).

---

## ✨ Features

- **Liquid Retina Glassmorphism:** Custom frosted glass surfaces (`backdrop-filter: blur()`), subtle inset specular highlights, and ambient light orbs.
- **Smart Image Lightbox:** Click any diagram or case study to trigger an Apple-style focus zoom with high-blur backdrops.
- **Integrated Rehearsal Teleprompter:** Press `N` at any point to slide out an off-canvas speaker drawer with conversational, calibrated stage notes.
- **Synthesized Audio Chime:** Embedded Web Audio API major chord sequence that rings out upon reaching the closing slide (with optional `.mp3` local fallback).
- **Keyboard & Click Controls:** Fully operable with presentation clickers, arrow keys, or custom dock navigation.
